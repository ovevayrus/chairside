# Chairside: Even Hub App Submission QA

Rubric: https://hub.evenrealities.com/docs/ship/app-submission (read 2026-11-24).

**Hardware status: simulator-verified.** Nothing here has run on G2 glasses: no QR sideload and no beta build on a locked phone. Every "pass" below is a static check of `apps/glasses/app.json`, a unit test, a command output or a simulator run (evenhub-simulator 0.9.5, SDK 0.0.16). Items marked "needs-hardware" cannot be proven in the simulator.

Status words: **pass** (proven by the evidence named), **simulator-only** (proven in the simulator; real device behaviour not seen), **needs-hardware** (cannot be proven without a G2), **needs-user** (a decision or asset only the user can supply).

Commands: `npm run e2e` (full run, writes `docs/evidence/e2e-full.md` and `e2e-full-NN-*.png`), `npm run e2e -- --idle` (2-minute idle check), `npm run pack` (builds the glasses app, then `evenhub pack app.json dist -o ../../chairside.ehpk --sdk-ver 0.0.16`).

## Still needs a real G2 (or the user)

1. System exit dialog drawing and its cancel gesture; the WebView closing after exit; other apps launching afterwards.
2. Locked-phone operation through a beta build from Beta Testing (a QR sideload stops when the WebView backgrounds), including unlock, another app, re-lock.
3. Setup remembered across a real relaunch (the simulator's bridge storage does not persist).
4. BLE timing: reconnect and tap latency over Bluetooth.
5. Real legibility of the brightness levels on the glasses display.
6. From the user: production server origin in the network whitelist, greyscale icon and background, changelog, store listing text, a published privacy policy URL naming the server domain, and proof that `chairsideapp.com` is the developer's.
